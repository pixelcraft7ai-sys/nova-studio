# NOVA Studio (نوفا ستوديو)

Arabic-first desktop creative studio (photo, paint, vector, layout). **Status: phase 00 —
engineering foundation only; there are no editing tools yet.** The name is provisional
pending a trademark check.

- Build & run: `BUILDING.md`
- Architecture decisions: `docs/architecture/decisions/`
- Progress, test results, open decisions: `docs/implementation-status.md`
- Product blueprint and phase plan are kept alongside the project (`blueprint-nova-studio-ar.md`, `NOVA-Studio-Workplan`).

Module layout: `core` · `document` · `render` · `formats` · `platform` · `app` (see ADR 0005).
