# 0008 — Project licence
Status: **Accepted (2026-10-11), owner decision**

**Decision.** The project stays proprietary and owned solely by the project owner. All rights reserved; no open-source licence is granted. `LICENSE` states this.
**Consequences.**
- Nothing may be published or shared outside the owner's control without a new decision.
- Qt is used under its open-source terms (LGPLv3) by linking dynamically to unmodified Qt. This is allowed for closed-source apps but carries obligations (ship Qt licence texts, let users replace the Qt libraries). **Open item:** confirm this is acceptable or buy a commercial Qt licence; get legal review before any public release.
- Contributors, if any are added later, need a contributor agreement first.
